# CAA 1.0 — Android

Version Android de CAA 1.0, inspirée des grands principes d'une application de CAA moderne : grille de pictogrammes, vocabulaire central, catégories, barre de phrase, synthèse vocale, favoris, recherche ARASAAC et personnalisation.

Cette interface est une conception originale : elle ne copie pas les éléments propriétaires de Proloquo2Go.

## Fonctionnalités
- grille adaptable ;
- catégories ;
- construction de phrase ;
- synthèse vocale française ;
- favoris ;
- recherche ARASAAC ;
- mode édition ;
- mode sombre ;
- réglage du nombre de colonnes.

## Compilation
Le workflow GitHub Actions produit un APK Android et un AAB Google Play.
